# TaskFlow Frontend

Interface simples em HTML, CSS e JavaScript puro para consumir a [TaskFlow API](https://github.com/jgcoderch/taskflow-api).

## Funcionalidades

- Cadastro e login de usuário
- Listagem, criação, edição e exclusão de tarefas
- Token JWT salvo no navegador (localStorage)

## Como rodar

1. Certifique-se de que a TaskFlow API está rodando (local ou em produção).
2. Ajuste a constante `API_URL` no `app.js` para apontar para o endereço correto da API.
3. Abra o `index.html` no navegador (ou use a extensão Live Server do VS Code).
